# Разработка сервиса по управлению рассылками

## Описание проекта

Данный проект представляет собой сайт сервис по управлению рассылками. 
Он включает в себя Django-проект, функционал которого релизован в приложении newsletters. 

Цели проекта:
1) Реализация моделей NewsletterRecipient, Message, Newsletter и NewsletterAttempting, организация связи между ними.
2) Настройка корректного отображения моделей в административной панели.
3) Подготовка шаблонов для отображения страниц сервиса.
4) Стилизация шаблонов с помощью Bootstrap.
5) Реализация котроллеров для отображения страниц.
6) Настройка маршрутизации для этих контроллеров.
7) Настройка подключения в проекте к  СУБД PostgreSQL, сокрытие чувствительных данных.
8) Реализация функционала по подтверждению регистрации по электронной почте.
9) Реализация функционала по восстановлению пароля.
10) Настройка прав доступа к данным и манипуляциям с данными в сервисе.
11) Настройка отображения статистики по рассылками для пользователей.
12) Реализация функционала для менеджеров сервиса, включая остановку рассылок и блокировку пользователей.
13) Реализация отправки рассылки через интерфейс и из командной строки.
14) Настройка серверного кеширования. 
15) Создание команды для наполнения базы данных группой "Менеджеры"

## Установка

1. Клонируйте репозиторий по ссылке https://github.com/SuperZebrocat/NewsletterApp

2. Установите необходимые зависимости: для работы над проектом необходимо установить Django.

4. Точка входа находится в модуле manage.py в корне проекта

## Использование
1. Для запуска сервера разработки выполните команду "python manage.py runserver".
2. Заглавная страница сайта находится по адресу http://127.0.0.1:8000/ - страница для логина или регистрации.
3. После успешной регистрации и авторизации пользователь получает доступ к функционалу сервиса.
